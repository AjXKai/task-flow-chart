## 🚀 Getting Started

Welcome to task-flow-chart! This application helps you create various types of diagrams easily. You can design work flows, logic flows, database tables, and more using a simple drag-and-drop interface. No programming knowledge required!

## 🔍 Features

- Draw multiple types of diagrams, including:
  - Activity Diagrams
  - Components Diagrams
  - Use Case Diagrams
- Intuitive drag-and-drop interface
- Customizable widgets
- Easy connection of widgets through visual links

## 🌟 System Requirements

- Windows, macOS, or Linux
- Latest version of your web browser (Chrome, Firefox, Safari, or Edge)
- Minimum 4 GB RAM
- 500 MB of available storage space

## 🛠️ How to Use task-flow-chart

1. **Open the Application:** Find the task-flow-chart app in your applications menu and launch it.
2. **Select a Diagram Type:** Choose the type of diagram you want to create from the main menu.
3. **Add Widgets:** Drag widgets from the left panel to the canvas area.
4. **Connect Widgets:** Click on the edge of one widget and drag to another to create a connection.
5. **Customize Widgets:** Click on any widget to edit its properties and customize its appearance.
